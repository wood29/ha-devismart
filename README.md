# DEVIreg Smart for Home Assistant

A Home Assistant app repository with a stabilized version of the community **Devismart MQTT** app for
DEVIreg™ Smart thermostats.

## Install

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fwood29%2Fha-devismart)

Or: **Settings → Apps → App store → ⋮ → Repositories**, add `https://github.com/wood29/ha-devismart`,
then install **DEVIreg Smart MQTT**. Setup and pairing: [devismart-mqtt/DOCS.md](devismart-mqtt/DOCS.md).

What changed compared to the original: [devismart-mqtt/CHANGELOG.md](devismart-mqtt/CHANGELOG.md).
